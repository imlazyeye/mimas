# mimas for VS Code

Syntax highlighting, snippets, and language configuration for [mimas](https://mim.as) `.mim` files.

The TextMate grammar's source of truth is `tools/highlighter/mimas.tmLanguage.json`; `npm run sync-grammar` copies it in (also runs automatically on `vsce package`). Press <kbd>F5</kbd> for an Extension Development Host.
