# Cart API

Everything a [lunacade](./lunacade.md) cart can call besides the [sandboxed std](../extension/advanced-usage.md#installer-functions): the `luna`, `gfx` and `input` modules, and the `Color`, `Button` and `Mouse` enums. All of them are in scope without a `use`. These pages are generated from the console's own API when the book is built, the way the [library reference](../std.md) is.
